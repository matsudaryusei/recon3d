## 5. 困ったときのメモ

**「これ何だっけ」という用語** → `internal/partner-questions-v1.md` の末尾に用語集があります（点群・メッシュ・ボクセル・バンドル調整など）。

**「分担が表と違う」** → それで正常です。[計画書 §3-6](3d-reconstruction-project-plan.md) の担当表はただの叩き台なので、実際にどう分けたかを[進捗ログ](3d-reconstruction-progress-log.md)に書いて、**表のほうを現実に合わせて直してください。**
