「勝手に決めていいのか分からない」 → 決めていいです。ただし決めたことは必ずIssueかPRのコメントに1〜2行残してください。 毎日会えるぶん口頭で済みがちですが、それだとGitHubに何も残らず、就活で見せる材料が減ります。

「これ誰がやるんだっけ」 → 決まっていないのが正常です。 計画書 §3-3 に作業ジャンル（G1〜G9）の一覧があるので、着手するときに取って、Issueに自分を入れてください。 人ごとの担当表は 8/16 に廃止しました（→ D-36）。
