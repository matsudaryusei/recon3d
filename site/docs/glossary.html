0. このプロジェクト特有の言い方#

文書のいたるところに出てくるので、ここだけは先に読んでください。

用語意味

1. 3D復元まわり#

用語意味
点群（point cloud）3D空間に浮かぶ点の集まり。まだ面になっていない状態
メッシュ三角形の面の集まり。3Dモデルの一般的な形式
ボクセル（voxel）3D版のピクセル。空間を細かい立方体で区切ったもの
シルエット / マスク物体の輪郭。「ここは物体、ここは背景」の白黒画像
Visual Hull / ボクセル彫刻複数方向のシルエットで、ボクセルの塊を外側から削って形を出す方法
多視点復元 / SfM複数枚の写真の対応点から、カメラの位置と3D点を同時に求める方法
ターンテーブル被写体を載せて回す台。カメラを固定したまま角度違いの写真が撮れる
真値（ground truth）正解の値。合成データでは Blender が正解を知っている
合成データ / 実写前者は Blender で作った画像、後者はカメラで撮った画像
凹み形状外から一直線に見えない窪み。シルエット法では原理的に削れない（→ D-02）

2. カメラまわり#

用語意味
内部パラメータ（intrinsics）焦点距離と主点（画像上で光軸が通る点。cx, cy）。カメラ本体の性質で、被写体によらない
外部パラメータ / カメラ姿勢（extrinsics）カメラがどこにあり、どちらを向いているか。回転 R と並進 t
歪み係数（distortion）レンズによる像の歪みを表す数値。k1, k2, p1, p2, k3 など
world → camera「世界座標の点をカメラ座標に移す向き」。逆向きと取り違えると鏡像や裏返りになる
光軸レンズの中心を通る、カメラが見ている方向の軸
右手系 / 左手系座標軸の向きの取り決め。XとYを決めるとZの向きが2通りあり、そのどちらか
画像座標画像上の位置 (u, v)。原点が左上か左下かはライブラリごとに違う
再投影誤差復元した3D点を画像に投影し直したとき、元の点とどれだけズレるか。単位は px
主点（principal point）光軸が画像面と交わる画像上の点（cx, cy）。ふつう画像の中心付近。「レンズの中心」という3次元上の点とは別物
キャリブレーション内部パラメータを事前に測っておく作業。チェッカーボードを使う

3. 数理まわり#

用語意味
同次座標3D点を4つ組 (x, y, z, w) で表す書き方。平行移動も行列の掛け算1回で書ける
DLT（Direct Linear Transform）対応点から、カメラ行列を線形の最小二乗として一気に解く方法
三角測量2枚以上の画像で同じ点を見て、その3D位置を求めること
バンドル調整カメラ姿勢と3D点を同時に微調整して、再投影誤差を最小化する処理
最小二乗誤差の2乗の合計が最小になる解を選ぶ考え方
SVD（特異値分解）行列を3つの行列の積に分解する道具。最小二乗や退化の判定に使う
条件数「入力の小さなズレが、答えをどれだけ大きく狂わせるか」を表す数。大きいほど不安定
疎行列（sparse matrix）ほとんどの成分がゼロの行列。ゼロを保存しないので巨大でも扱える
CG法（共役勾配法）対称正定値な連立一次方程式を、逆行列を作らずに反復で解く方法
前処理（preconditioner）反復解法が早く収束するように、問題の形を整える工夫
LM法（Levenberg–Marquardt）非線形の最小二乗を解く定番の反復法
ヤコビアン各変数を少し動かしたとき出力がどれだけ動くかを並べた行列
Schur補元大きな連立方程式を、一部の変数を消して小さくする変形
収束する反復を回すと答えが1点に落ち着くこと。落ち着かない＝「収束しない」（振動する／停滞して進まない／発散する、のいずれか）。「収束しない＝発散」ではないので、判定①（11/1）ではどれなのかまで見る
ILU(0)前処理の一種。疎行列の構造を保ったまま近似的に分解する
チャンク分割大きな配列を小分けにして順に処理すること。メモリに載りきらないときの常套手段

4. メッシュまわり#

用語意味
Marching Cubesボクセルの塊から三角形メッシュを取り出す定番アルゴリズム
メッシュ簡略化 / QEM三角形の数を減らして軽くすること。QEM はその代表的な指標
ラプラシアン平滑化各頂点を周りの平均に寄せて、メッシュのデコボコをならす処理
cotan重みメッシュの辺に付ける重みの一種。三角形の角度から決まる
UV展開3Dの表面を2Dの平面に開くこと。テクスチャを貼るために要る
テクスチャ投影撮った写真の色を、メッシュの表面に貼り付けること
Hausdorff距離2つの3D形状のズレの指標。「各点から相手の形状までの最大距離」。単位は mm
閉じたメッシュ（watertight）穴が開いておらず、内と外が定義できる状態

5. 画像処理まわり#

用語意味
セグメンテーション画像を「物体」と「背景」などに分けること
背景差分背景だけの画像との差を取って、物体を切り出す方法
特徴点（feature）画像の中で目印になる点（角など）。別の写真でも同じ点を見つけられる
マッチング2枚の画像の特徴点どうしを対応づけること
二値化画像を白（255）と黒（0）だけにすること。中間値を残さない
アルファチャンネル画像の「透明度」の層。背景を透明にしてレンダリングすると使える
Holdout / Cryptomatte / ID MaskBlender で特定のオブジェクトだけを抜き出す仕組みの名前（→ T07）
コンポジタ（Compositor）Blender で、レンダリング結果を後から加工するための画面。ノードをつないで使う
レンダリング3Dのシーンから2Dの画像を計算して作ること
ポリゴンメッシュを構成する面。ふつう三角形。数が多いほど細かいが重い
ビューア結果を見るためだけの画面。本プロジェクトでは L4（余力があれば）の項目
EEVEE / CyclesBlender のレンダリング方式。前者は速い、後者は物理的に正確
bpyBlender を Python から操作するためのモジュール
.blend / .obj / .ply / glTF3Dデータのファイル形式。何で出すかは T02 で決めます

6. 開発まわり#

用語意味
uvPython の環境とパッケージを管理するツール。本プロジェクトの標準（→ 計画書 §7-1）
NumPy配列と行列計算のライブラリ。本プロジェクトの計算はほぼこの上に載る
OpenCV（cv2）画像処理のライブラリ。自作した結果の答え合わせにも使う（計画書 §9-1 第2層）
SciPy科学計算のライブラリ。疎行列や既製のソルバがある。答え合わせ用
Open3D点群・メッシュを扱うライブラリ
Matplotlibグラフを描くライブラリ。実験結果の図に使う
NumbaPython の重い部分を機械語に落として速くする道具。C++ を導入しない代わりの手（→ 計画書 §3-8）
pyproject.tomlプロジェクトの設定ファイル。Python のバージョンや依存を書く
uv.lock実際に入れた依存の版を1つ残らず固定したファイル。3台で同じ環境になる根拠
仮想環境 / .venvこのプロジェクト専用の Python 置き場。他のプロジェクトと混ざらない
editable installsrc/ を編集したら即反映される形でのインストール。これで import recon3d がどこからでも通る（→ D-38）
型ヒント（type hint）def f(x: int) -> str: のように型を書き添える書き方。動作は変わらないが読み手と道具が助かる
dataclass値を持つだけのクラスを短く書くための仕組み
シグネチャ（signature）関数の「形」。名前・引数・引数の型・戻り値の型のこと。中身（実装）は含まない
docstring関数やクラスの直下に書く説明文。""" で囲む
フィールドJSON やデータ構造の中の1項目（例：cameras.json の source）
smoke test「とりあえず起動するか」だけを見る最小のテスト
fixture（pytest）テストで使う共通の準備物。pytest が用意してくれる仕組み
回帰テスト「前は動いていたものが壊れていないか」を確かめるテスト
E2E テスト入口から出口まで通しで動かすテスト
CIpush や PR のたびに自動でテストを回す仕組み。本プロジェクトは GitHub Actions（→ T03）
リポジトリプロジェクト1つぶんの置き場。履歴ごと丸ごと入っている
clone（クローン）GitHub 上のリポジトリを、自分のPCに丸ごと持ってくること。最初の1回だけ
commit（コミット）変更に区切りを付けて履歴に刻むこと。まだ自分のPCの中だけ
push（プッシュ）自分のPCの commit を GitHub に送ること
pull（プル）GitHub の最新を自分のPCに取り込むこと
origin「GitHub 側のリポジトリ」を指す既定の呼び名
main本流のブランチ。完成した内容だけが入る（→ T04 で直接の書き込みを禁止します）
staging（git add）「次の commit にこれを含める」と印を付ける段階。add を忘れると commit に入りません
ブランチ（branch）作業用の枝。main を触らずに好きなだけ commit できる
PR（プルリクエスト）「この枝を main に入れてください」という申請。議論の場でもある
squash merge（スカッシュマージ）枝の commit を1個にまとめて main に入れる方式
conflict（コンフリクト・衝突）2人が同じ行を別々に直したとき、Git がどちらを採るか決められない状態。<<<<<<< ======= >>>>>>> の3行ごと消して、残したい内容だけにすれば直る
ブランチ保護main への直 push を禁止する設定（→ T04）
.gitattributes改行コードなどの扱いを統一する設定ファイル。Windows 混在対策
.gitignoreGit に追跡させないファイルを並べた設定。.venv/ や data/ を除外している
ターミナルコマンドを打ち込む黒い画面。mac は「ターミナル」、Windows は「PowerShell」
フルパスファイルの居場所を先頭から全部書いたもの（例：/Applications/Blender.app/...）。どこから実行しても確実に届く

AssigneeGitHub の Issue に付ける「この人がやります」の印。着手する時点で自分を入れる運用です
