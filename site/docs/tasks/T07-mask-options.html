なぜやるのか#

マスク（被写体の形だけを白、背景を黒にした画像）は、シルエット復元＝ボクセル彫刻の入力そのものです。 ここが濁ると、このプロジェクトの最重要実験 E5 の数字が意味をなさなくなります。

何を比較するのか（4方式）#

Blender で被写体だけを切り出す代表的なやり方が4つあります。 この4つを調べて表にします。

#方式ざっくり何をするか
1アルファチャンネル（Film > Transparent）背景を透明にしてレンダリングし、PNG の α を取り出して二値化する
2Holdout（オブジェクトのマスク設定）特定オブジェクトを「穴」として扱わせ、そこだけ抜く
3Cryptomatteオブジェクト単位の ID を持ったパスを出力し、目的のオブジェクトの ID だけ抜く
4Compositor の ID Mask / Object Indexオブジェクトに番号を振り、コンポジタで番号一致の画素だけ取り出す
