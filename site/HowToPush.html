gitへの反映方法#

もし自分が編集する場合は、

git add .
git commit -m "更新内容(変更者の名前)"
git push origin main

リアルタイム同期ではないの、誰かが編集したら最新版を取得する必要がある

git pull origin main

で呼べるよ！
