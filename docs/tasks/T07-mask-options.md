## なぜやるのか

**マスク（被写体の形だけを白、背景を黒にした画像）は、シルエット復元＝ボクセル彫刻の入力そのものです。**
ここが濁ると、**このプロジェクトの最重要実験 E5 の数字が意味をなさなくなります。**

**そして、いま2人ともマスク生成をやったことがありません。** 8/16 の確認では「判断できない」という回答でした。
だから **「経験がある人に委ねる」ではなく「材料を作ってから2人で決める」** に切り替えました（[D-35](../decisions.md#d-35)）。

**この作業は「決める」ことではありません。「決められる状態にする」ことです。**

---

## 何を比較するのか（4方式）

**Blender で被写体だけを切り出す代表的なやり方が4つあります。** この4つを調べて表にします。

| # | 方式 | ざっくり何をするか |
|---|---|---|
| 1 | **アルファチャンネル（Film > Transparent）** | 背景を透明にしてレンダリングし、PNG の α を取り出して二値化する |
| 2 | **Holdout（オブジェクトのマスク設定）** | 特定オブジェクトを「穴」として扱わせ、そこだけ抜く |
| 3 | **Cryptomatte** | オブジェクト単位の ID を持ったパスを出力し、目的のオブジェクトの ID だけ抜く |
| 4 | **Compositor の ID Mask / Object Index** | オブジェクトに番号を振り、コンポジタで番号一致の画素だけ取り出す |
