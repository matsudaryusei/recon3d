## 決める5件

**この順に聞いてください。** 下線の項目は「決まらなかった」で終わらせず、**「いつまでに決めるか」だけでも決めてください。**

### ① 最終成果物として何が欲しいか

**選択肢**（複数可）:

- テクスチャ付きメッシュ（`.obj` / `.ply`）
- `.blend` ファイル
- glTF
- **デモ動画**（回転させて見せる）
- **復元過程の可視化動画**（ボクセルが削られていく様子）

**なぜ聞くか**：出したい形が決まると、`mesh/texture.py` と `viz/` にどれだけ時間を割くかが決まります。glTF なら書き出しコードが要りますが、`.blend` なら Blender 側で済みます。

### ② 撤退ライン L1〜L4 と判定時期の認識合わせ

[計画書 §12](../plan.md#s12) の表を**その場で開いて読み合わせます。**

確認する3点：

1. **目標は L3**（統合パイプライン＋比較実験）で合っているか
2. **11/1 にバンドル調整が収束していなければ L2 に落とす**ことに納得できるか
3. **11/29 にメッシュが破綻していれば L1 に落とす**ことに納得できるか

> **「頑張ればいける」で先延ばしにしないための線です。** L1 でも L2 でも成果物にはなるように組んであります。

### ③ 週の進め方

- 作業しやすい曜日・時間帯
- **連絡手段**（連絡帳（`Notice.md`・public 化で廃止） を使う頻度。返信までどのくらいを期待するか）
- 週1回15分の「次週の Issue を切る会」をいつやるか（[計画書 §8-3](../plan.md#s8-3)）

### ④ メッシュ処理をどこまで自作するか

**現在の想定**（[計画書 §3-3](../plan.md#s3-3)）:

| 項目 | 想定 |
|---|---|
| Marching Cubes | **自作** |
| メッシュ簡略化（QEM） | **自作** |
| ラプラシアン平滑化 | **自作**（`solvers/cg.py` を呼ぶ） |
| テクスチャ投影 | **自作** |
| **UV展開** | **Blender の Smart UV Project を使う**（自作しない） |

**この線引きで合っているかを確認します。** 自作範囲が増えると G4 の 65h が膨らみます。

| **決まらない／どちらでもよさそう** | **「いつ決めるか」だけ決めて次へ行く。** 15分の枠を守るほうが大事です。決めた期日は [計画書 §16](../plan.md#s16) に書く |

| **その場で意見が割れた** | **どちらが正しいかを決めようとしない。** 「どういう条件ならどちらを選ぶか」を書き出して持ち帰る。判断材料が足りないだけのことが多いです |
