## なぜ「凹み」が必須なのか

**このプロジェクトは2つの復元手法を組み合わせて、片方の弱点をもう片方で埋めるのが芯です。**

| 手法 | 苦手な条件 |
|---|---|
| ① 多視点復元（特徴点ベース） | **無地でテクスチャのない面** → 特徴点が取れず、点群に穴が空く |
| ④ シルエット復元（ボクセル彫刻） | **凹んだ形状** → 原理的に削れない（外から見えない窪みは彫れない） |

**両方の弱点を同時に持つ被写体でないと、「組み合わせた意味」が数字に出ません。**
つまり **無地の面 ＋ 凹み** の両方が要ります。**マグカップがちょうどこの2つを満たします**（陶器の無地の面＋内側の窪み）。

> **凹みの無いモデルを選ぶと、最重要実験 E5 が成立しません。** ここだけは妥協できない条件です（→ [D-02](../decisions.md#d-02)）。

## 探す条件

| # | 条件 | 判定のしかた |
|---|---|---|
| 1 | **内側に凹みがある** | 断面を想像して、**外から一直線に見えない窪みがあるか**。マグカップの内側・壺・お椀・ヘルメットの内側など |
| 2 | **無地の面がある** | 全面に模様が入っていないこと。**木目や布のテクスチャで覆われたモデルは①が有利になりすぎる** |
| 3 | **閉じたメッシュ**（穴が空いていない） | 真値との比較に使うため。板だけのモデルは不可 |
| 4 | **ポリゴン数が極端でない** | 数千〜数十万程度。数百万は Blender が重くなる |
| 5 | **ライセンスが確認できる** | **下記参照** |

**探す場所の例**：Poly Haven / Blender の公式デモファイル / Sketchfab の CC0・CC-BY 絞り込み / Thingiverse など。**「マグカップ」「cup」「mug」「bowl」で探すのが早いです。**

**副データ（`synthetic_bunny`）も1つ確保してください**（[計画書 §2](../plan.md#s2)）。

**こちらは主データと条件が逆です。** 目的は**「①（多視点復元）が最も上手くいく条件で、どこまでの性能が出るか」を測ること**なので、

| 副データの条件 | なぜ |
|---|---|
| **テクスチャが豊富**（模様・色の変化が多い） | **特徴点がたくさん取れる**必要があります。無地だと①が本来の力を出せません |
| **凹みが少ない** | 凹みは④の弱点を見るためのもので、こちらの目的ではありません |

> ⚠️ **名前に引きずられないでください。** `synthetic_bunny` はデータセットの呼び名で、**Stanford Bunny をそのまま使う指定ではありません。**
> **Stanford Bunny は無彩色のスキャンデータでテクスチャを持たず、耳の間や顎の下に凹部もあります。** そのまま使うと上の2条件を満たしません。
> **テクスチャを貼って使うか、条件に合う別のモデルを選んでください。** どちらにするかは選ぶ人が決めてよいので、**選んだ理由をメモに1行残してください。**

## ライセンスで見るところ

**このリポジトリは完成後に public 化する前提です**（[D-27](../decisions.md#d-27)）。**モデルをコミットしなくても、成果物の画像に写ります。**

| ライセンス | 使えるか | 必要なこと |
|---|---|---|
| **CC0 / Public Domain** | ◎ そのまま使える | 表記は任意（**それでも書いておく**） |
| **CC-BY** | ○ 使える | **作者名・出典 URL・ライセンス名の表記が必須** |
| **CC-BY-SA** | △ 使えるが注意 | 派生物にも同じライセンスが要求される。**避けたほうが無難** |
| **CC-BY-NC** | ✕ **避ける** | 非商用限定。就活での提示は微妙なので使わない |
| **不明・記載なし** | ✕ **使わない** | 確認できないものは候補に入れない |

> **`data/` は `.gitignore` で除外されています**（[計画書 §6](../plan.md#s6)）。**モデル本体はコミットしません。**
> **コミットするのは「どこから取ってきたか」の記録だけ**です。それがこのメモです。

## つまずいたら

| 症状 | 対処 |
|---|---|
| **ライセンスがどこにも書いていない** | **候補から外す。** 「確認できないものは使わない」が本プロジェクトの方針です（public 化するため） |
| **凹みがあるか判断できない** | **断面を想像する。**「外から一直線に見えない窪みがあるか」だけです。マグカップの内側・お椀・壺・ヘルメットの内側が該当します |
| 良いモデルだがポリゴン数が数百万ある | 候補には残してよいですが、**「重い」と備考に書く**。Blender の Decimate で減らせますが、その手間も見積もりに入ります |
| **モデルが `.fbx` や `.gltf` で、開けるか不安** | Blender はどれも読めます。**開けたかどうかを備考に書けば十分**です |
| **全面にテクスチャが貼ってある** | **条件2（無地の面）を満たしません。** ただし Blender でマテリアルを外せば無地にできるので、「加工が要る」と書いて候補に残してよい |
| **テクスチャ付きの副データが見つからない** | **形と模様は別々に調達できます。** 凹みの少ないモデル（Stanford Bunny・Blender 内蔵の Suzanne など）を取ってきて、**テクスチャ画像を貼る**のが早道です。**その場合は「テクスチャは別途貼った」とメモに書いてください**（後で E5 の条件を説明するときに要ります） |
| **1時間で3件そろわない** | **2件でも出す。** 2件あれば比較になります |
