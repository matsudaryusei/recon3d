# ドキュメントの HTML 版を作る

md をそのまま HTML にして `site/` に出すスクリプトです。**md が原本**なので、
本文を直したいときは md を編集して、これを流し直してください。

```bash
python3 docs/tools/build_html.py
```

出力できたら `site/index.html` をブラウザで開きます（ダブルクリックでも開けます）。

| ファイル | 役割 |
|---|---|
| `build_html.py` | 全体の変換とページの組み立て。トップページの並び順もここ（`INDEX`） |
| `mdparse.py` | md → HTML の変換本体。依存ライブラリなし |
| `style.css` | 見た目。`site/assets/style.css` にコピーされる |

## 決めていること

- **出力先はリポジトリ直下の `site/`。** `docs/` の階層をそのまま写すので、
  md 同士の相対リンク（`../plan.md#s12` など）が `.html` のまま通ります。
- **`site/` は毎回まるごと作り直します。** そこに手で書き足しても消えます。
- 対応している記法は、この docs で実際に使っているものだけです
  （見出し・表・箇条書き・チェックボックス・引用・コードブロック・
  強調・打ち消し・リンク・`<a id="...">` アンカー）。
  新しい記法を使いたくなったら `mdparse.py` に足してください。
- **md 以外のファイル（`tools/*.py` など）へのリンクは、HTML では文字だけ残してリンクを外します。**
  `site/` に出力されないため、リンクにすると切れるからです（md 側のリンクはそのまま残します）。

## 新しい md を足したとき

`docs/` 以下に置けば自動で拾われます。トップページの見える場所に出したいときは
`build_html.py` の `INDEX` に1行足してください。足さなくても「その他」に出ます。
