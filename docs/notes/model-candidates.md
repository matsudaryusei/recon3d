# 合成データ用 3Dモデルの候補

**条件**: 凹み形状が必須（計画書 §2・D-02）。無地の面があること。閉じたメッシュであること。

## 主データ候補（`synthetic_cup` 相当・凹みあり）

### 候補1（推す案）
- 名前 / URL: Ceramic Pot / https://polyhaven.com/a/ceramic_pot
- ライセンス: CC0
- 作者: Aron Łyczek（Poly Haven）
- ファイル形式（.blend / .obj / .fbx など）: Poly Haven配布形式（.blend / .fbx / .gltf など選択可）
- ポリゴン数: 4K tris
- **凹みの確認**: 蓋は本体と一体で分離できないが、蓋部分の面をBlender上で非表示にして内部を確認したところ、お椀状の深い内壁が実際にモデリングされていた。両側面の取っ手もループ状で凹みとして機能する
- **無地の面の確認**: 全面が経年劣化（weathered）による色ムラのみで、柄・模様の類は一切無い
- 良い点 / 気になる点: 良い点＝Non Manifoldチェックで穴が検出されず閉じたメッシュを確認済み、3候補中最も軽量（4K tris）。気になる点＝蓋が本体と一体のため、実験で「蓋を開けた状態」が必要な場合は編集作業が発生する

## 副データ候補（`synthetic_bunny`・**テクスチャが豊富・凹みが少ない**）

## 推す案

**主データは Ceramic Pot（候補1）を推す。** 理由は、Non Manifoldチェックで閉じたメッシュであることが確認済みで追加の修復作業が不要な点、内部の凹みが実在することを目視で確認できている点、模様が一切無く条件を明確に満たしている点、そして3候補中最も軽量（4K tris）な点。Pot Enamel 01は無地と模様の混在が実験的に面白いが持ち手の修復が必要、自作マグカップは加工の自由度が高く将来的な有力候補だが現時点では凹みが未作成のため、まずはCeramic Potで進めるのが最も手戻りが少ない。

**副データは Food Lychee 01（候補1）を推す。** 主データ（無地・凹みあり）と正反対の条件を最もはっきり満たすためで、ウロコ状の突起による特徴点の豊富さと、凹みの無い球形という2点が揃っている。Food Pomegranate 01 は同等の条件を満たしつつテクスチャの性質が異なる（突起の陰影ではなく色の濃淡）ので、E5 の条件を振りたいときの差し替え先として残す。
