# 合成データ用 3Dモデルの候補

**条件**: 凹み形状が必須（計画書 §2・D-02）。無地の面があること。閉じたメッシュであること。

## 主データ候補（`synthetic_cup` 相当・凹みあり）

### 候補1（推す案）
- 名前 / URL: Ceramic Pot / https://polyhaven.com/a/ceramic_pot
- ライセンス: CC0
- 作者: Aron Łyczek（Poly Haven）
- ファイル形式（.blend / .obj / .fbx など）: Poly Haven配布形式（.blend / .fbx / .gltf など選択可）
- ポリゴン数: 4K tris
- **凹みの確認**: 蓋は本体と一体で分離できないが、蓋部分の面をBlender上で非表示にして内部を確認したところ、お椀状の深い内壁が実際にモデリングされていた。両側面の取っ手もループ状で凹みとして機能する
- **無地の面の確認**: 全面が経年劣化（weathered）による色ムラのみで、柄・模様の類は一切無い
- 良い点 / 気になる点: 良い点＝Non Manifoldチェックで穴が検出されず閉じたメッシュを確認済み、3候補中最も軽量（4K tris）。気になる点＝蓋が本体と一体のため、実験で「蓋を開けた状態」が必要な場合は編集作業が発生する

### 候補2
- 名前 / URL: Pot Enamel 01 / https://polyhaven.com/a/pot_enamel_01
- ライセンス: CC0
- 作者: Kuutti Siitonen（Poly Haven）
- ファイル形式（.blend / .obj / .fbx など）: Poly Haven配布形式（.blend / .fbx / .gltf など選択可）
- ポリゴン数: 11K tris
- **凹みの確認**: 蓋が分離できる構造になっており、外すと内部の凹みを直接確認できる
- **無地の面の確認**: 上部〜中央は無地の濃茶色エナメル。底部のみ炎柄の装飾が入る
- 良い点 / 気になる点: 良い点＝無地の面と模様のある面がバランス良く同居しており、多視点復元・シルエット復元どちらの弱点も作りやすい。気になる点＝持ち手の付け根がNon Manifold（非閉塞）。使用前に`メッシュ` → `クリーンアップ` → `穴を埋める`等での修正が必要

### 候補3（自作・要加工）
- 名前 / URL: マグカップ.blend（自作、`data/myself/マグカップ.blend`）
- ライセンス: 自作（オリジナル、表記不要）
- 作者: 本人（自作）
- ファイル形式（.blend / .obj / .fbx など）: .blend
- ポリゴン数: 円柱（本体）1,660 tris + トーラス（持ち手）1,152 tris ＝ 合計約2,812 tris
- **凹みの確認**: 現状は本体（円柱オブジェクト）が中身の詰まった状態で凹みは未作成。採用時に上面の面を選択→インセット→下方向に押し出し、という手順で面を削除せずに凹みを作る予定（削除方式だと非閉塞になるため回避）
- **無地の面の確認**: マテリアルは「白」「茶色」の2色のみで模様は無い
- 良い点 / 気になる点: 良い点＝自作のためライセンス確認が不要、本体・持ち手ともNon Manifold 0件で閉じたメッシュは既に達成済み。気になる点＝①現状サイズが2m×2m×2mと非現実的なため縮小が必要、②凹み自体は未加工で採用決定後に作業が発生する

## 推す案

**Ceramic Pot（候補1）を推す。** 理由は、Non Manifoldチェックで閉じたメッシュであることが確認済みで追加の修復作業が不要な点、内部の凹みが実在することを目視で確認できている点、模様が一切無く条件を明確に満たしている点、そして3候補中最も軽量（4K tris）な点。Pot Enamel 01は無地と模様の混在が実験的に面白いが持ち手の修復が必要、自作マグカップは加工の自由度が高く将来的な有力候補だが現時点では凹みが未作成のため、まずはCeramic Potで進めるのが最も手戻りが少ない。
